## LinkedIn

I have released **AI Value Investing Agents v1.0.0**, the first stable version of an English-first, multi-agent value-investing research framework for Claude Code and OpenAI Codex.

The project turns investment research from a loose prompt into a repeatable process with:

- 20 canonical English workflows shared across Claude Code and Codex
- primary-source and current-date requirements
- exact valuation and financial calculations
- explicit uncertainty and evidence labels
- blocking decision gates
- report-audit tooling
- portfolio and investment-thesis monitoring
- validated installation on Ubuntu, macOS, and Windows

Codex also includes a dedicated reporting overlay for turning validated research into decision-ready long-form reports.

The project is independently maintained and derived from the original AI Berkshire framework by xbtlin, with clear lineage and attribution.

I released an open-source multi-agent value-investing research framework for Claude Code and Codex

### Body

I have released **AI Value Investing Agents v1.0.0**, an English-first framework that packages fundamental-investment research into reusable workflows for Claude Code and OpenAI Codex.

The motivation was that general AI prompts can sound convincing while skipping important research controls. The workflows therefore require current-date confirmation, primary-source evidence, exact arithmetic for decision-sensitive calculations, explicit uncertainty labels, blocking gates, and a report-audit step.

The release contains 20 canonical workflows covering company and private-company research, earnings, financial data, industry screening, management, income investing, portfolio review, thesis tracking, thesis-drift detection, and long-form publishing. Claude Code and Codex use the same canonical workflow sources.

Installation is tested on Ubuntu, macOS, and Windows. The repository is independently maintained and derived from the original AI Berkshire project by xbtlin, with clear attribution.
