The design uses a solid dark background so it remains legible on platforms that do not preserve transparency.

## GitHub Requirements

GitHub accepts PNG, JPG, or GIF images smaller than 1 MB. It recommends at least 640 × 320 pixels and 1280 × 640 pixels for best display.

Official documentation:

https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview

## Upload Procedure

1. Open the repository on GitHub.
2. Select **Settings**.
3. Locate **Social preview**.
4. Select **Edit**.
5. Choose **Upload an image**.
6. Upload the prepared 1280 × 640 PNG.
7. Save the change.
8. Test the repository URL in the sharing interface of the target platform.

The social-preview setting is repository metadata rather than a tracked repository file, so adding the SVG source to the repository does not activate it automatically.

## Design Content

The preview communicates:

- project name;
- v1.0.0 English Edition status;
- Claude Code and OpenAI Codex compatibility;
- 20 shared workflows;
- the research sequence `Sources → Analysis → Decision`;
- the project's evidence, valuation, and audit focus.

## Safe-Area Check

Important text is kept away from the outer edges so common social-card crops do not remove the project name or product description. Before final publication, verify the card on the specific networks where it will be shared.
