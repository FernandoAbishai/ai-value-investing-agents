# AI Value Investing Agents v1.2.0 — Upstream Sync and Research Index

**Release date:** 2026-10-12

AI Value Investing Agents v1.2.0 is a backward-compatible minor release that brings the maintained English edition forward from the August reliability release to the current 21-workflow framework, completes a selective upstream review through October 12, 2026, and adds a deterministic research-report index with publication-safety controls.

## Highlights

- Adds `era-alpha` as the 21st canonical shared workflow, with synchronized Claude Code, Codex skill, and optional Codex prompt surfaces.
- Strengthens long-horizon investment research with terminal-value and IRR audit tooling that enforces currency consistency, denominator-width checks, and explicit treatment of discrete risks.
- Adds a hardened report-index pipeline for the historical archive, generating both human-readable and machine-readable inventories.
- Publishes an initial index of 2,203 tracked reports across 109 company groups and 16 themes.
- Adds a full-history, read-only GitHub Actions gate that blocks stale generated report indexes.
- Records a selective upstream review through October 12, 2026 instead of mirroring upstream research output wholesale.

## Report Index and Publication Safety

The new `tools/reports_index.py` generator creates:

- `reports/README.md` for human navigation;
- `reports/index.json` for machine-readable inventory and downstream tooling.

The generator deliberately indexes only report contents represented in Git's index. It excludes:

- untracked local drafts;
- ignored files;
- `git add -N` intent-to-add placeholders.

If Git index state cannot be read, generation fails closed rather than risking publication of local-only material.

Additional hardening includes:

- Unicode-stable Git-history handling;
- explicit UTF-8 console behavior on Windows;
- temporary-Git regression tests across publication-boundary cases;
- fork-specific classification of curated `reports/examples/` as `Verified English examples` rather than a company;
- exclusion of `reports/examples/VERIFICATION.md` from the report inventory because it is a source/calculation register, not a report.

The first committed index was generated from a full-history checkout and verified immediately with:

```bash
python3 tools/reports_index.py
python3 tools/reports_index.py --check
```

The permanent `Report Index` workflow now runs the read-only `--check` gate on pull requests and `main` pushes.

## Upstream Synchronization

This release formalizes selective semantic synchronization with the original `xbtlin/ai-berkshire` repository.

The review covered reusable framework, tooling, correctness, and maintenance changes through upstream commit `ab56abcb31ef8e3a92d925f1b18fb339341ac9d3` from October 12, 2026.

The review intentionally does not treat commit-count parity as a goal. Large batches of upstream-specific research reports, portfolio records, publishing assets, and generated media are not imported automatically when they do not improve the reusable framework.

The review boundary and policy are documented in `docs/UPSTREAM_REVIEW_2026-10.md`.

## Workflow and Tooling Changes Since v1.1.0

### New shared workflow

- `era-alpha`: identifies core alpha within secular high-growth themes, tests growth durability, anchors valuation, and defines falsifiable holding and exit signals.

### Long-horizon valuation discipline

`tools/terminal_value.py` and the maintained `investment-research` workflow add auditable long-horizon valuation checks, including:

- currency-aware required-return assumptions;
- `r - g` denominator-width gates;
- terminal-value and IRR calculations;
- separation of discrete risks from discount-rate assumptions;
- publication-time revalidation of valuation inputs.

### Generated-surface consistency

The maintained inventory is now:

- 21 canonical shared workflows;
- 21 generated Codex shared skill packages;
- 21 optional generated Codex prompts;
- 1 declared Codex-only package: `investment-memo-craft`.

## Upgrade

Update the repository checkout, then refresh managed installations:

```bash
git pull --rebase origin main
./scripts/manage.sh update --all
./scripts/manage.sh doctor --all
```

Windows uses `scripts\manage.bat` with the same subcommands.

## Important Limitations

- The historical report archive contains point-in-time research and should not be interpreted as current recommendations.
- The generated index improves navigation and reproducibility; it does not independently validate every historical report's claims.
- AI-generated research can contain factual, mathematical, sourcing, or interpretation errors.
- Verify filings, currencies, units, share counts, tax assumptions, and calculations independently.
- Nothing in this repository is personalized investment, legal, accounting, or tax advice.
