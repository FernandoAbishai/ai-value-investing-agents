# AI Value Investing Agents v1.0.0 — English Edition

This is the first tagged release of the maintained English-first edition of AI Value Investing Agents.

## Highlights

- All 20 canonical shared workflows under `skills/` are available in English.
- Claude Code and OpenAI Codex share those same canonical workflow sources.
- Codex installs 20 generated shared skill packages plus the hand-written Codex-only `investment-memo-craft` report overlay.
- Twenty optional Codex slash prompts are generated for the shared workflows and checked for drift.
- Installation is validated on Ubuntu, macOS, and Windows.
- Research workflows include stronger current-date, primary-source, exact-arithmetic, audit, attribution, privacy, and uncertainty requirements.
- Real-investor-inspired workflows are framed as interpretations rather than impersonations or endorsements.

## Included Workflow Areas

- public- and private-company research;
- multi-agent investment analysis;
- earnings and financial-data review;
- industry mapping, screening, and bottleneck discovery;
- management, portfolio, income, and thesis monitoring;
- long-form research and publication workflows;
- a Codex-only decision-report writing and layout overlay.

## Installation

Clone the maintained repository:

```bash
git clone https://github.com/FernandoAbishai/ai-value-investing-agents.git
cd ai-value-investing-agents
```

Claude Code:

```bash
./scripts/install-claude-commands.sh
```

OpenAI Codex:

```bash
./scripts/install-codex-skills.sh
./scripts/install-codex-prompts.sh
```

Windows equivalents are available as `.bat` scripts in `scripts/`.

See `docs/QUICKSTART_DEMO.md` for a complete installation and workflow walkthrough.

## Migration from the Original Checkout Name

The active maintained repository and example checkout directory are now:

```text
FernandoAbishai/ai-value-investing-agents
~/ai-value-investing-agents
```

Users with an older local clone should update the remote URL or clone the maintained repository again. Generated prompts now reference the maintained checkout name.

## Validation

The release commit must pass:

```bash
python3 scripts/sync-codex-skills.py --check
python3 scripts/sync-codex-prompts.py --check
python3 -m compileall -q scripts tools
```

GitHub Actions additionally verifies on Ubuntu, macOS, and Windows:

- 20 canonical shared workflows;
- 20 matching generated Codex shared skills;
- exactly one declared Codex-only skill, `investment-memo-craft`;
- 20 generated optional prompts;
- clean installation of 20 Claude Code commands, 21 Codex skills, and 20 Codex prompts.
