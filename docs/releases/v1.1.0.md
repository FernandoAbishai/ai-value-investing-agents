# AI Value Investing Agents v1.1.0 — Reliability and Operations

AI Value Investing Agents v1.1.0 turns the post-v1.0.0 reliability work into a stable release. It adds repository-wide quality controls, deterministic financial-tool tests, verified English research examples, unified installation management, and structured community feedback.

This is a backward-compatible minor release. The 20 canonical workflow names, Claude Code commands, generated Codex skill names, and optional Codex prompts remain unchanged.

## Highlights

- Repository-wide quality gates for local links, URL structure, maintained identity, private paths, high-confidence secrets, operational-language drift, and workflow inventory.
- Sixty deterministic tests covering financial calculations, report auditing, Taiwan-stock transformations, verified examples, installer safety, and community templates.
- Three point-in-time verified English reports with source registers and executable audit fixtures.
- Unified installation, update, diagnostics, and safe uninstall management for Claude Code and OpenAI Codex.
- Structured GitHub issue forms, support boundaries, feedback triage, a video demonstration script, and a publication checklist.
- Stronger release validation before a GitHub tag and release can be created.

## Quality and Financial Correctness

The permanent validation workflow now blocks:

- broken local Markdown targets and malformed external URL structure;
- stale maintained-project names or checkout paths on active surfaces;
- private local paths and high-confidence credential patterns;
- non-English operational workflow drift;
- missing or extra canonical workflows, Codex packages, or prompts.

Financial-tool improvements include:

- restricted arithmetic AST evaluation with `Decimal` instead of float-based `eval`;
- correct deviation handling for negative cross-source values;
- rejection of empty source sets;
- failure when an audit contains no verified data;
- failure when a single supplied source materially disagrees with the report;
- deterministic FinMind request and transformation tests without live API dependency.

## Verified English Research Examples

The release includes three educational, point-in-time examples under `reports/examples/`:

- Microsoft FY2026 company research;
- Microsoft FY2026 Q4 earnings review;
- a definition-aware comparison of Microsoft, AWS, Google Cloud, and Oracle.

Each example states its research cutoff, sources, calculations, limitations, and investment-advice boundary. Selected figures are represented in executable fixtures that must receive a `PASS` verdict in CI.

## Unified Installation Management

Recommended installation:

```bash
git clone https://github.com/FernandoAbishai/ai-value-investing-agents.git
cd ai-value-investing-agents
./scripts/install.sh --all
```

Windows:

```bat
git clone https://github.com/FernandoAbishai/ai-value-investing-agents.git
cd ai-value-investing-agents
scripts\install.bat --all
```

Management commands:

```bash
./scripts/manage.sh update --all
./scripts/manage.sh doctor --all
./scripts/manage.sh uninstall --all
```

The manager supports:

- component-specific installation;
- `--dry-run`;
- external manifests;
- SHA-256 drift detection;
- collision and modified-file backups;
- JSON diagnostics;
- refusal to delete modified managed entries without explicit `--force`.

The previous component-specific shell and batch installers remain supported aliases.

## Validation

The release commit must pass:

```bash
python3 scripts/repository_quality.py
python3 scripts/sync-codex-skills.py --check
python3 scripts/sync-codex-prompts.py --check
python3 -m compileall -q scripts tools tests
python3 -m unittest discover -s tests -v
```

The release workflow also verifies the unified install, doctor, idempotent update, and uninstall lifecycle before publishing the tag.

## Compatibility

- Claude Code: 20 canonical commands.
- OpenAI Codex: 20 generated shared skills plus the Codex-only `investment-memo-craft` overlay.
- Optional Codex prompts: 20 generated prompts.
- Tested operating systems: Ubuntu, macOS, and Windows.

No workflow was renamed and no installed destination changed by default.

## Upgrade

Update the repository checkout, then run the manager from the new version:

```bash
git pull --rebase origin main
./scripts/manage.sh update --all
./scripts/manage.sh doctor --all
```

Windows uses `scripts\manage.bat` with the same subcommands.

## Important Limitations

- Verified example reports are point-in-time educational artifacts, not current recommendations.
- Historical reports remain primarily in their original language and may contain data tied to their publication date.
- AI-generated research can contain factual, mathematical, sourcing, or interpretation errors.
- Verify filings, currencies, units, share counts, tax assumptions, and calculations independently.
- Nothing in this repository is personalized investment, legal, accounting, or tax advice.
